# Put your own copy of the game here

Copy your disc image of **Harvest Moon: Back to Nature (USA, SLUS-01115)** into this folder:
the `.cue` file and its `.bin` file (any file names). Then run `python build.py` in the
repository root.

Everything in this folder except this file is ignored by git, so your disc image is never
committed. See the main [README](../README.md#bring-your-own-copy) for how to make the image
from your disc.
